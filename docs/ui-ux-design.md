### 2.1 登录页 `/login`

**目的**：教师身份验证，获取 JWT Token

```
┌─────────────────────────────────────────────┐
│                                             │
│              📐 协同题库系统                 │
│                                             │
│  ┌─────────────────────────────────┐        │
│  │  欢迎回来                        │        │
│  │                                 │        │
│  │  用户名  ┌─────────────────┐    │        │
│  │         │ 输入用户名       │    │        │
│  │         └─────────────────┘    │        │
│  │                                 │        │
│  │  密码    ┌─────────────────┐    │        │
│  │         │ 输入密码         │    │        │
│  │         └─────────────────┘    │        │
│  │                                 │        │
│  │  ┌─────────────────────────┐    │        │
│  │  │       登 录              │    │        │
│  │  └─────────────────────────┘    │        │
│  │                                 │        │
│  │  还没有账号？[注册]              │        │
│  └─────────────────────────────────┘        │
│                                             │
└─────────────────────────────────────────────┘
```

**交互流程**：
1. 输入用户名 + 密码 → 点击登录
2. 前端调用 `POST /api/v1/auth/login`
3. 成功后 JWT 存入 `localStorage` / 内存
4. 跳转到 `/dashboard`
5. 失败显示错误提示（"用户名或密码错误"）

**状态**：loading / error / success

**数据流**：
```
表单 → validate → POST /api/v1/auth/login
  → 200: { token, user_id, display_name, role }
  → localStorage.setItem("token", token)
  → 跳转 /dashboard
```

### 2.2 注册页 `/register`

**目的**：新教师注册账号

与登录页类似，多出几个字段：

| 字段 | 类型 | 验证 |
|------|------|------|
| 用户名 | 文本 | 必填，唯一 |
| 邮箱 | email | 必填，格式 |
| 显示名称 | 文本 | 必填 |
| 密码 | 密码 | 必填，≥6位 |
| 确认密码 | 密码 | 与密码一致 |

**交互**：
- 注册成功后自动跳转登录页，提示"注册成功，请登录"

### 2.4 题目列表 `/questions`

**目的**：浏览、搜索、过滤所有题目

这是最核心的页面，功能最多：

```
┌──────────────────────────────────────────────────────┐

│                                                      │
│  ┌─ 筛选栏 ────────────────────────────────────────┐ │
│  │  题型: [全部 ▼]  难度: [全部 ▼]  状态: [全部 ▼]  │ │
│  │  年级: [全部 ▼]  知识点: [选择 ▼]               │ │
│  └─────────────────────────────────────────────────┘ │
│                                                      │
│  [➕ 新建题目]                                        │
│                                                      │

│  │  ─────────────────────────────────────────────── │ │
│  │  □  │ 已知二次函数...  │ 解答题│ 🔴难 │ ✅发布│ [详情] │

│  │  □  │ ...             │ ...   │ ...  │ ...  │ ...  │
│  └─────────────────────────────────────────────────┘ │
│                                                      │
│  ◀ 1 2 3 ... 10 ▶   每页 20 条                       │
│                                                      │
└──────────────────────────────────────────────────────┘
```

**筛选条件**（映射到后端 `GET /questions` 的 Query 参数）：

| 前端组件 | 后端参数 | 说明 |
|----------|----------|------|
| 关键词输入 | `keyword` | stem ILIKE 搜索 |
| 题型下拉 | `question_type` | choice/fill/solution/judgment |
| 难度下拉 | `difficulty` | easy/medium/hard |
| 状态下拉 | `status` | draft/pending/rejected/published/disabled |
| 年级下拉 | `grade` | 初一~高三 |
| 知识点选择器 | `knowledge_point_id` | 树形选择 |
| 分页 | `page`, `page_size` | 默认 20 |

**交互细节**：
- 立即搜索：输入关键词后 300ms 防抖自动触发搜索
- 筛选变更立即刷新列表
- 行点击 → 跳转到题目详情页
- 批量操作（后续）：勾选多题 → 批量提交审核

**空状态**：搜不到结果时显示"没有找到匹配的题目"

```
│  │  ✅ A. [内容...]    ✔ 正确答案                   ││
│  │  □  B. [内容...]                                ││
│  │  □  C. [内容...]                                ││
│  │  □  D. [内容...]                                ││

│                                                      │
│  ┌─ 答案与解析 ────────────────────────────────────┐│
│  │  正确答案 │ 已在上方勾选                          ││
│  │  解析    │ [富文本编辑器]                        ││
│  └─────────────────────────────────────────────────┘│
│                                                      │

│  │  ☐ 数与代数                                      ││

│  │    ☐ 实数                                        ││

│  └─────────────────────────────────────────────────┘│
│                                                      │
│  [💾 保存草稿]  [🚀 提交审核]                         │
│                                                      │
└──────────────────────────────────────────────────────┘
```

**题型切换**：选择不同题型时，下方区域动态切换：

| 题型 | 特有字段 |
|------|----------|
| **选择题** | 选项列表（A/B/C/D+）、正确答案勾选 |
| **填空题** | 填空位标记（在题干中用 `____` 定位）、每个空位的答案 |
| **解答题** | 分步评分标准（步骤名 + 分值） |
| **判断题** | 正确/错误 单选 |

**编辑状态处理**：

| 状态 | 操作 |
|------|------|
| 草稿 | 可自由编辑、保存、删除 |
| 驳回 | 可编辑（自动回退为草稿状态）、保存后需重新提交 |
| 待审核/已发布/已停用 | 只读，不可编辑 |

**按钮逻辑**：
- "保存草稿" → `POST /api/v1/questions` 或 `PUT /api/v1/questions/:id`
- "提交审核" → 保存 + `POST /api/v1/questions/:id/submit`
- 保存后跳转到题目详情页

**表单验证**：
- 题干必填
- 至少一个正确答案
- 选择题至少 2 个选项
- 至少关联一个知识点

- 删除前检查是否有题目关联

**数据获取**：`GET /api/v1/knowledge-points` → 返回嵌套 JSON 树

## 3. 前端路由设计

```
/login                    → 登录页
/register                 → 注册页

/                         → 重定向到 /dashboard
/dashboard                → 工作台

/questions                → 题目列表（支持 Query 参数）
/questions/new            → 创建题目
/questions/:id            → 题目详情
/questions/:id/edit       → 编辑题目

/review                   → 审核队列
/review/:id               → 审核题目（同详情页 + 审核操作区）

/knowledge-points         → 知识点管理
```

**路由守卫**：
- 所有 `/` 下的路由需要已登录（有有效 JWT）
- `/login` 和 `/register` 在已登录时自动跳转 `/dashboard`
- 审核相关路由额外检查 `role === "groupleader" || role === "admin"`

## 5. 数据流架构（前端建议）

```
┌─────────────────────────────────────────────────────┐
│                      React 组件树                      │
│  Pages → Components → UI Primitives                   │
├─────────────────────────────────────────────────────┤
│                     状态管理                           │
│  ┌─────────────────────────────────────────────┐    │
│  │  Auth Context  │ 当前用户、JWT token         │    │
│  │  Query Client  │ 服务端数据缓存（react-query）│    │
│  └─────────────────────────────────────────────┘    │
├─────────────────────────────────────────────────────┤
│                     API 层                           │
│  ┌─────────────────────────────────────────────┐    │
│  │  axios / fetch 实例                           │    │
│  │  - 自动附加 Authorization: Bearer <token>    │    │
│  │  - 401 时自动跳转到 /login                   │    │
│  │  - 统一错误处理                               │    │
│  └─────────────────────────────────────────────┘    │
├─────────────────────────────────────────────────────┤
│                     后端 API                          │
└─────────────────────────────────────────────────────┘
```

### 建议技术栈

| 层 | 推荐 |
|----|------|
| 框架 | **React 18+** + TypeScript |
| 路由 | **React Router v6** |
| 状态/数据 | **TanStack Query (react-query)** — 服务端缓存 |
| UI 组件库 | **Ant Design** 或 **shadcn/ui** |
| 公式渲染 | **KaTeX** 或 **MathJax** |
| 富文本 | **TipTap** (基于 Prosemirror) |
| HTTP 请求 | **axios** 或 **fetch** |

## 6. 页面状态覆盖清单

| 状态 | 展示 |
|------|------|
