# 协同题库系统 — 用户使用手册

> 版本：v0.2 · 适用于 2026-07-12 后版本
> 目标读者：终端教师、教研组长、平台管理员

---

## 1. 系统简介

本系统是一个**多教师协同的数学题库平台**，支持：

- 题目录入、审核、发布
- 个人 / 团队 / 公共三种题库空间
- 灵活审题：个人自审 / 团队协作 / 指定审题人
- 知识点分类与检索
- 手动组卷

## 2. 账号与登录

### 2.1 登录

访问系统首页 → 输入用户名、密码 → 点击「登录」。

### 2.2 注册

点击登录页底部「注册」链接，填写用户名、邮箱、密码、显示名完成注册。

**注册后自动获得**：
- 1 个**个人空间**（默认私有，可自审）
- 可加入或创建团队空间
- 可浏览公共题库

### 2.3 测试账号

| 用户名 | 密码 | 角色 | 用途 |
|--------|------|------|------|
| `admin2` | `123456` | Admin | 用户管理、公共库治理 |
| `teacher1` | `123456` | User | 个人空间录题/自审、团队协作 |

## 3. 空间模型

### 3.1 三种空间

系统通过「空间」组织题目归属与权限：

| 空间类型 | 说明 | 谁可写 | 审题方式 |
|----------|------|--------|----------|
| **个人空间** | 你私有的题库 | 仅本人 | **录入人可自行审核发布** |
| **团队空间** | 多人协作题库 | 空间成员 | **创建者回避**，由团队其他成员审 |
| **公共题库** | 全站共享 | 不可直接写 | 通过「贡献」流入 |

### 3.2 切换空间

页面顶部有**空间切换器**下拉框：
- 列出你所属的所有空间（个人 + 已加入的团队 + 公共库）
- 切换后，题目列表、Dashboard 等会按当前空间过滤
- 默认选中你的个人空间

## 4. 题目录入

### 4.1 新建题目

1. 顶部导航 →「录题」按钮（或题目列表页「新建题目」）
2. 选择当前空间（个人 / 团队）
3. 填写题干（支持 LaTeX，用 `$...$` 包裹公式）
4. 选择题型：
   - **选择题**：录入选项 A/B/C/D，勾选正确答案
   - **填空题**：逐空录入答案
   - **解答题**：录入参考答案与分步评分标准
   - **判断题**：选择正确 / 错误
5. 录入解析（可选）
6. 设置难度（简单 / 中等 / 困难）、年级、知识点等属性
7. 点击「保存」（草稿）或「提交审核」

### 4.2 编辑与自动保存

- 编辑页**双栏布局**：左侧编辑、右侧实时预览（含 LaTeX 渲染）
- 分隔条可拖拽调整左右比例
- 草稿自动保存

### 4.3 协作设置（团队空间）

在团队空间录题时，可展开「协作设置」面板：

- **指定审题人**：勾选团队成员（可多选，**自动排除自己**）
  - 不选 → 由团队其他成员审
  - 选了 → **仅**被勾选的人能审
- **内部备注**：仅审核员可见的命题意图或讨论要点

> 个人空间无需指定审题人，默认自审。

## 5. 审题流程

### 5.1 三种场景

| 场景 | 空间 | 规则 |
|------|------|------|
| **个人自审** | 个人空间 | 录入人可一键审核发布自己的题 |
| **团队协作** | 团队空间 | 录入人**不能**审自己录入的题，由团队其他成员审 |
| **指定审题** | 团队 / 个人 | 仅被指定的审题人能审 |

**优先级**：指定审题人 > 空间默认规则。

### 5.2 提交审核

题目处于 `draft` 状态时，在题目详情页点击「提交审核」：
- 状态变为 `pending`（待审核）
- 题目锁定，不可编辑
- 团队空间可在提交弹窗中指定审题人

### 5.3 审核操作

**进入审核队列**：
- 顶部导航 →「审核队列」
- 列表只显示**当前用户有权审核**的题（后端按权限过滤）
- 个人空间：自己录入的 pending 题
- 团队空间：他人录入的 pending 题（创建者会自动被排除）
- 指定审题：被指定给你的 pending 题

**审核动作**：
- 进入题目详情页
- 点击「通过」→ 状态变为 `published`（已发布）
- 点击「驳回」→ 弹窗填写驳回原因 → 状态变为 `rejected`

### 5.4 状态流转

| 状态 | 含义 | 可执行操作 |
|------|------|-----------|
| draft | 草稿 | 编辑、提交审核、删除 |
| pending | 待审核 | 通过、驳回（仅审题人） |
| rejected | 已驳回 | 重新编辑（生成新版本） |
| published | 已发布 | 引用组卷、贡献到公共库 |
| disabled | 已停用 | 仅 Admin 可操作 |

## 6. 团队协作

### 6.1 创建团队空间

调用空间 API `POST /api/v1/spaces` 创建团队空间（首期通过 API；前端 UI 待补全）。

### 6.2 添加成员

调用 `POST /api/v1/spaces/:id/members` 添加成员。

### 6.3 协作规则

- 团队中**录入与审查角色可轮流替换**，无固定分工
- 任何成员都可录题
- 任何成员（除创建者外）都可审题
- 提交时可指定特定审题人

> 团队空间**录入者不能审自己录入的题**，这是硬编码的安全约束。

## 7. 公共题库

### 7.1 浏览公共库

空间切换器选择「公共题库」→ 浏览全站已贡献题目。

### 7.2 贡献到公共库

将你空间内**已发布**的题目贡献到公共库：
- 题目详情页 →「贡献到公共」按钮
- 系统会**复制**一条新题到公共空间（保留原题不动）
- 新题记录 `origin_question_id` 指向原题

### 7.3 从公共库导入

将公共库题目导入到你的个人 / 团队空间：
- 公共题详情页 →「导入」按钮
- 选择目标空间
- 系统复制一条新题到目标空间，可独立修改

> 采用**复制**而非引用，避免公共库改动影响你已组好的试卷。

### 7.4 Admin 治理

Admin 可对公共题执行「下架」操作，状态变为 `disabled`，不可再被组卷引用（已有引用不受影响）。

## 8. 试卷组卷

### 8.1 新建试卷

1. 顶部导航 →「试卷」→「新建试卷」
2. 填写标题、学科、年级、用时等
3. 保存为草稿

### 8.2 添加题目

- 试卷编辑页 →「添加题目」
- 从题库检索（仅显示已发布题）
- 设置每题分值（覆盖默认分值）
- 调整题目顺序

### 8.3 发布试卷

试卷编辑完成后点击「发布」，状态变为 `published`。

## 9. 知识点管理

### 9.1 浏览知识点树

顶部导航 →「知识点」→ 树形展示数学知识点分类。

### 9.2 维护

- 新增 / 重命名 / 移动知识点节点
- 删除前会检查是否有题目关联

> 知识点树**首期全局共享**，不按空间隔离。

## 10. 管理员功能

仅 Admin 角色可见：

### 10.1 用户管理

顶部导航 →「用户管理」：
- 查看全站用户列表
- 角色显示为「管理员」/「普通用户」

### 10.2 公共库治理

- 浏览公共题库
- 对违规题目下架

### 10.3 系统运维

- 可查看所有空间（治理需要）
- 可审核任何 pending 题（运维兜底）

## 11. 常见问题

### Q1：我录的题为什么审核队列里看不到？

- **个人空间**：你录入的题默认由你自己审，会出现在你的审核队列
- **团队空间**：录入者**不能审自己录入的题**，所以你录入的题不会出现在你的审核队列，需要团队其他成员审
- **指定审题人**：如果提交时指定了其他人，只有被指定的人能审

### Q2：怎么让自己录的题自己审？

切换到**个人空间**录题 → 提交 → 在审核队列中审核通过。

### Q3：团队成员都能审我录的题吗？

- 若你**未指定审题人** → 团队中所有其他成员（非创建者）都可审
- 若你**指定了审题人** → 仅被指定的人能审

### Q4：公共库的题改了会影响我的试卷吗？

不会。公共库流通采用**复制**语义，你导入到空间的题是独立副本。

### Q5：题目被驳回了怎么办？

- 题目状态变为 `rejected`
- 在题目详情页查看驳回原因
- 点击「编辑」修改 → 重新提交审核（生成新版本）

### Q6：怎么切换当前工作空间？

页面顶部空间切换器下拉框，选择目标空间即可。切换后所有列表按新空间过滤。

### Q7：LaTeX 公式怎么输入？

用 `$...$` 包裹行内公式，例如：
- 行内：`$x^2 + y^2 = r^2$`
- 块级：`$$\int_0^1 x \, dx = \frac{1}{2}$$`

## 12. 题型支持速查

| 题型 | 答案结构 | 是否支持分步评分 |
|------|----------|-----------------|
| 选择题 (choice) | 选项 + 正确选项字母 | 否 |
| 填空题 (fill) | 多空答案列表 | 否 |
| 解答题 (solution) | 参考答案 + 评分步骤 | 是 |
| 判断题 (judgment) | true / false | 否 |
