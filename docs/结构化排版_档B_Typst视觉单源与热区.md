## 一、目标与动机

| 痛点（终稿路径） | 档 B 目标 |
|------------------|-----------|
| 每个 `variant` 须 HTML + Typst 双侧登记，易漂移 | **消除双端皮肤维护**：皮肤 / 母版 / 公式视觉只在 Typst |
| 编辑画布是结构投影，校对才是印张 | **编辑区也可接近印张**：所见与 PDF 同引擎 |
| 长卷下 HTML + KaTeX 盒皮仍是性能压力源 | 编辑面以 **当前页 SVG + 热区** 为主，不再依赖全量 KaTeX 盒皮 |

产品交互不变：老师仍用「对象树 / 装盒子 / 套样式 / 调文档模板」；变的是中栏视觉源。

---

## 二、架构

```
PublicationDocument（唯一可写）
        │
        ▼ compile（与校对 / 导出同一管线）
typst_gen → 当前页 SVG + 块 bbox 元数据
        │
        ▼ 前端投影
IR 全量持有 + 当前页 SVG + 透明热区（点选 → selectedId）
```

| 层 | 职责 |
|----|------|
| **`PublicationDocument`** | 唯一可写真相源；结构 / 样式 / 文档模板；画布不存第二套坐标 |
| **Typst** | **唯一**皮肤 / 母版 / 公式视觉真相；校对与导出同源编译 |
| **前端** | IR 全量；中栏挂 **当前页 SVG**；其上叠 **透明热区** 承接点选 |
| **对象树 / 右栏** | 与终稿一致：树选中 ↔ `selectedId`；文档模板 \| 对象属性 |

校对 Tab 与编辑面在档 B 下可共用同一 SVG 管线（仍只挂当前页）；不再维护「印刷级 HTML 皮肤组件库」作为可保存样式的视觉源。

## 三、与终稿 / 档 A 对照

| 维度 | 终稿（现行） | 档 A（＝终稿 §3.4 结构态口径） | **档 B（本文所述优化方案）** |
|------|--------------|--------------------------------|----------------------|
| 编辑中栏 | HTML 工作画布（虚拟化）+ 校对 Tab 单页 SVG | 结构态长卷为主；内容靠邻域展开；校对仍单页 SVG | **当前页 SVG + 透明热区**；可选邻页预取 |
| 皮肤登记 | HTML 组件 + Typst 函数，几乎同款 | 同终稿（结构态可弱化盒皮） | **仅 Typst**；前端不维护印刷级 CSS 皮肤库 |
| 视觉一致性 | 双端 token / 肉眼接近；分页以 Typst 为准 | 结构态与印张差距更大，靠校对 Tab 对齐 | 编辑所见与 PDF **同引擎**；分页/盒皮/公式视觉同源 |

| 生效方式 | 主线默认 | 可选折中 | **增强方案**；不覆盖终稿，显式切换后才取代 §3.3 |

## 四、交互（继承终稿，换命中面）

仍沿用终稿 §3.1 / §3.2：

- **主路径**：选中对象 → 套样式集 / 装进多栏盒 / 拆盒 / 排序；未选中或进入「版面」→ 调文档模板。  
- **公式编辑**：默认不在排版画布内改 LaTeX；题面仍引用 `question_id`。  
- **双层模板**：文档模板（`doc.page`）与对象样式（`style_sets` / `box_style`）分离；母版区点进版面面板，**不可**当正文块拖拽改几何。

档 B 差异仅在命中：

| 动作 | 行为 |
|------|------|
| 点正文块热区 | → `selectedId`；右栏出对象属性 |
| 点母版区热区（页眉/页脚/水印等） | → 打开「文档模板」面板；不设正文 `selectedId` |
| 点空白 / 无映射区 | 保持或清空选中（产品可选）；不写坐标到 IR |
| Ctrl/⌘ + 点热区、框选 | **多选**（装盒前提）；多选状态不写坐标到 IR |
| 拖拽热区排序手柄 | 只改 `body` 顺序；落点由 IR 结构决定，**不写几何** |
| 重叠热区（徽章压住题面等） | 命中优先级：**深层块优先**（children > 盒子 > 母版区）；同层取先命中 |
| 编辑后选中块跨页迁移 | 视图自动跳至该块所在页并维持高亮 |

装盒 / 拆盒 / 套样式的数据变更仍只写 `PublicationDocument`；视觉靠 debounce 全文热重编、只换当前页 SVG（沿用现有 `/typeset/preview` 节奏，重编口径见 §六）。

## 五、命中映射（档 B 关键）

| 项 | 口径 |
|----|------|
| 映射 | 块 `id` → **页内 bbox**（单一路线：`typst_gen` 为每个 `LayoutBlock` 挂 label，编译期经 query / 帧树导出 `id → bbox` JSON，随 `PreviewResponse` 扩展字段下发；实现基础：`compiler.rs` 已走帧树） |
| 母版区热区 | 页眉/页脚/水印不在 body 块流，同样靠编译期 label 导出 bbox；命中打开「文档模板」面板 |
| 热区 | 透明 overlay，几何与 bbox 对齐；点击命中 id |
| 跨页块 | 每页各自 bbox；选中态可跨页高亮同一 id（实现可选） |
| **无 bbox** | **降级**：侧栏对象树选中；不阻塞结构编辑 |
| 禁止 | 把热区坐标回写为 IR 几何真相；自由拖拽改印刷坐标（非主线） |

bbox 契约可后置于 `typst_gen` / preview API；文档侧先冻结「有则热区、无则树」的产品行为。

## 六、性能（硬约束，对齐终稿并收紧视觉侧）

教师讲义可达 **150～200 页**。档 B 与终稿 DOM 纪律一致，并明确不再依赖全量 KaTeX 盒皮。

| 规则 | 要求 |
|------|------|
| 禁止 | **整卷 SVG** 一次挂进 DOM |
| 中栏 | **只挂当前页** SVG（邻页预取 ±1，LRU 上限 ≤5 页，防内存回升） |
| IR | **全量**持有于内存；与 DOM / SVG 规模脱钩 |
| 对象树 | 可虚拟滚动 |
| 公式 / 盒皮 | 视觉在 Typst SVG 内；**不再**以全量 KaTeX + HTML 盒皮支撑编辑面 |
| 重编 | **始终全文重编**（Typst 分页是全局布局结果，不存在按页重编）；靠 comemo 增量缓存的热编译 + debounce + 过期请求丢弃控制延迟 |
| 编译延迟 | 热重编预算 **P95 < 2s**（百页讲义实测填数；基建见 `compiler.rs` cold/warm 对比测试） |
| 反馈模型 | **乐观更新**：对象树 / 右栏即时反映数据变更，SVG 与热区延迟到达；超预算时编辑期降级结构态轮廓，校对再上 SVG |

性能验收：一屏内挂载页数与总页数近似无关；百页+ 文档可滚动、可点选，不因整卷 SVG/KaTeX 卡死。

## 八、明确不做

- **Typst → HTML** 作为主编辑画布（反向生成可编辑 DOM）  
- 前端 **印刷级 CSS 皮肤库** 作为可保存样式的视觉源（档 B 下）  
- **整卷 SVG** 进 DOM  
- 自由画框 / 钢笔 / 复杂绕排 / 图层（与终稿一致）  
- 用热区坐标污染 `PublicationDocument` 几何  
- 覆盖或改写终稿正文以「静默生效」档 B  

**已知损失（切换时接受）**：

- 编辑面 SVG **文本不可划词选中 / 复制**（typst-svg 把字形描成 `<path>`）；对策：右栏对象属性提供题面文本，必要时保留只读文本层。  
- 编辑反馈存在**编译延迟**（相对 HTML 画布的零延迟）；对策：乐观更新 + 结构态降级（见 §六）。
