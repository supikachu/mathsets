## 二、排版主线清单

### 2.1 愿景锚点

> 老师用「对象树 / 装盒子 / 套样式 / 调文档模板」组卷排版；Typst 负责公式、分页、PDF。  
> **对齐教辅向 InDesign 的真实用法**（框 + 样式 + 栏 + 母版），**不做通用 InDesign**（自由钢笔、任意图层、绕排等）。

教辅向 InDesign ↔ 本产品对照：

| 教辅向 InDesign | 本产品 |
|-----------------|--------|
| 文本框 / 题组框 | `PubBlock`（题、节、盒） |
| 对象样式 | `style_sets` / `box_style`（声明式 `variant`，禁止编辑态自由路径） |
| 母版 / 文档设置（页眉页脚页码、栏、边距） | `doc.page` → `LayoutSpec` + profiles |
| 钢笔描花边（模板期画一次） | 皮肤库登记；用户只套样式 |
| JS 灌题 / 批处理 | 试题篮装配 + `PublicationDocument` 编译 |

### 2.2 分期

| 阶段 | 目标 | 交付物 |
|------|------|--------|
| **P0**（已完成） | 子系统边界 | 排版文档；`PublicationDocument` IR；独立 `/studio` 壳；试题篮入口接入 |
| **P1** | 可编辑结构 + 性能纪律 | 对象树选中 + **undo/redo**；HTML 工作画布（点选 + **块级虚拟化**）；中栏编辑/校对 Tab；右栏「文档模板 \| 对象」骨架 |
| **P2** | 容器化与双端皮肤 | `MultiColumnBox` 插入/移除；样式集保存/套用；`typst_gen` 映射同名皮肤；双端登记约定；**编译 API 契约落定（§4.6）** |
| **P2.5**（可选） | 档 B 技术验证 | bbox spike（label + 帧树/query 导出）；热区点选原型；百页热重编延迟实测（§六） |
| **P3** | 文档种类与母版扩展 | `kind` → 默认 profile 映射落地；文本块、封面块；底色/水印/品牌页眉等文档模板字段按需落地 |
| **P4** | 持久化 | 排版文档存库 / 本地；与 `papers` 可选关联（含已存试卷 → Studio 路径） |
| **P5+**（可选） | 增强 | 档 B 视觉单源切换（§六）；结构态默认长卷、片段 mark、typst.ts、模板市场、缩略小地图（简化 Canvas） |

### 2.3 P0～P2 详细主线（执行优先级）

1. **`PublicationDocument` IR**（前端类型 + 文档契约；后端可后置）  
2. **`/studio` 沉浸式工作台**（三栏壳：树 / 画布|预览 / 文档模板·对象属性）  
3. **试题篮 → Studio**（sections → Document 装配，含往返一致性 §4.7）  
4. **对象树只读 → 可排序 + undo**（树可虚拟滚动）  
5. **工作画布（HTML，虚拟化）与 Typst 校对预览切换**（校对只挂当前页 SVG）  
6. **`MultiColumnBox` + 样式集**（HTML 皮肤 + Typst 同名函数）  
7. **`LayoutDoc` / `typst_gen` 增加容器块与皮肤映射**（后端 IR 变更面见 §4.6）  
8. **导出 PDF 吃 PublicationDocument 编译结果**

### 2.4 明确不做（主线外）

- 自由画框、钢笔路径描边、复杂绕排、图层  
- 字符级任意选中改样式（P5 前不做）  
- 新建切断题库的独立 Git 仓库 / 独立后端  
- 解冻 Word 格式 parity  
- **整卷 HTML + 全量 KaTeX 常驻 DOM**（150～200 页教师讲义场景下会卡死）  
- **Canvas / WebGL 作为主编辑画布**（公式与 `LatexRender` 复用成本高；本产品是结构化块编辑，非自由画布）  
- 前端任意 CSS / 无法映射到 Typst 的「一次性皮肤」

## 三、交互模型与双层模板

### 3.1 交互状态机（产品口径）

- **唯一可写真相源**：`PublicationDocument`；画布不存第二套坐标。  
- **主路径**：选中对象 → 套样式集 / 装进多栏盒 / 拆盒 / 排序；未选中或进入「版面」→ 调文档模板参数。  
- **公式编辑**：默认不在排版画布内改 LaTeX；题面仍引用 `question_id`，改公式走录题链路。  
- HTML 画布 = 可交互的结构与皮肤投影；Typst = 印刷与分页真相。

**撤销 / 重做（P1 必备）**：

- 浅层 command stack：装盒 / 拆盒 / 排序 / 套样式 / 删块 / 文档模板参数变更均可撤销；
- 历史深度下限 50 步；预览编译不进入历史。

**块操作全集（P1/P2 口径）**：

| 操作 | 口径 |
|------|------|
| 排序 | **先上下移按钮**（虚拟列表下拖拽有坑），拖拽排序 P2 后补 |
| 从文档移除题目 | 允许；**单向**，不回写试题篮 |
| 追加题目 | Studio 内不提供选题，**必须回试题篮**（往返规则见 §4.7） |
| 题号 `display_no` | 排序后默认**自动重编**；手动改过的值保留并标记 |
| 删除文本块 / 提示块 | 允许，可 undo |

**`kind` 口径**：P3 前 `kind`（exam / handout / topic）**仅为元数据**，切换不影响 profile / 母版；P3 落地 `kind` → 默认 profile / 封面差异的映射。

### 3.2 双层模板

| 层 | 职责 | 数据 |
|----|------|------|
| **文档模板（母版）** | 页码、页眉页脚、纸张/边距、全局栏数与栏间距、首页/正文差异、字体、全局底色/水印/品牌页眉（扩展） | `doc.page` → 现有 `LayoutSpec`（`frontend/src/api/types/layout.ts`）+ `/typeset/profiles` |
| **对象样式（盒子皮肤）** | 题/盒外框：侧签、顶徽章、花角线框、底色卡片等 | `style_sets[]`、`style_set_id`、`box_style` |

- Studio 右栏：**文档模板**（版面）与 **对象属性** 分开；勿把页眉页脚参数塞进单题皮肤。  
- **全局栏**（`page.columns` + `margins.gutter_mm`）与 **盒内栏**（`multi_column_box.columns`，P2 起可加 `column_widths`）**并存**，旋钮不混用。  
- 母版在画布上的投影（页眉/页脚/水印区）可点进「文档模板」，**不可**当正文块随意拖拽改几何。

**region 样式集映射**：`StyleSet.scope` 含 `region`（section_title / stem / option）。与 `LayoutSpec.fonts` 的分工：`fonts` 定**字体族**，region 样式定**字号 / 字重 / 颜色**，编译为 Typst 分层 `#set text(...)` 规则（区域作用域），不进入盒子皮肤契约。

### 3.3 HTML ↔ Typst 视觉一致（几乎同款）

> 备选优化路径：档 B（视觉单源 = Typst，见本文 §六；显式启用前以本节双端口径为准）。

```
StyleSet + LayoutSpec（单一契约）
        ├─→ HTML 皮肤组件（Studio 编辑画布）
        └─→ typst_gen 皮肤/母版函数（SVG 校对 / PDF）
```

| 目标 | 口径 |
|------|------|
| 版心、边距、栏、盒皮、色、圆角、页眉页脚 | **几乎一致**（共享 token / mm；网页加载与导出同系字体，优先思源宋/黑） |
| 分页切口 | **以 Typst 为准**；HTML 编辑态可为连续流 + 虚拟列表 |
| 公式 | 同源 LaTeX；画布 KaTeX、导出 mitex→Typst；**不承诺**字形级一致；失败两侧同规则预检 |

纪律：

- 新皮肤必须 **HTML + Typst 同时登记**；禁止只改一端。  
- 禁止无法映射到 Typst 的自由 CSS 作为可保存样式。  
- 改结构/样式后校对 Tab debounce 重编（沿用现有预览节奏）。

### 3.4 长文档与性能（硬需求）

教师讲义可达 **150～200 页**（含多解解析）。卡顿主因是 **KaTeX 公式 DOM 膨胀**，不是「页框个数」。

**DOM 侧**：

| 规则 | 要求 |
|------|------|
| 禁止 | 整卷 HTML + 全量 KaTeX 一次挂进 DOM |
| HTML 画布 | **块级虚拟列表**（仅视口 ±N；选型 `vue-virtual-scroller`，已在依赖）；公式 IntersectionObserver / `requestIdleCallback` 懒渲染；滚出可销毁子树 |
| 长卷体验 | 允许 **结构态**（题号/盒轮廓/徽章，不全文 KaTeX）与选中邻域 **内容展开** |
| Typst 校对 | **只挂当前页 SVG**（与 `TypesetPreview.vue` 一致） |
| 对象树 | 可虚拟滚动；**IR JSON 全量持有**，与 DOM 规模脱钩 |
| 主编辑技术 | HTML + 现有 `LatexRender`；不以 Canvas/WebGL 作主编辑面 |

**编译侧**：

| 规则 | 要求 |
|------|------|
| 重编 | **始终全文编译**（Typst 分页是全局布局结果，不存在按页重编）；靠 comemo 增量缓存的热编译 + debounce + **过期请求丢弃** 控制延迟 |
| 延迟预算 | 百页讲义热重编 **P95 < 2s**（实测填数；基建见 `compiler.rs` cold/warm 对比测试） |

**性能验收口径（P1 起，可测）**：

- 一屏内 DOM/公式量与总页数近似无关；
- 200 页文档：DOM 节点 < 5000、挂载的 KaTeX 子树 < 50、滚动无 >100ms 长任务；
- 结构编辑可滚动、可点选，不因全量渲染卡死。

## 四、PublicationDocument 设计

编辑态真相源；**不是** Typst 源码，也不是最终 `LayoutDoc`。

### 4.1 与现有层的关系

```
题库 Question
    ↓ 引用
PublicationDocument（Studio 编辑 / 可持久化）
    ↓ compile
ExamRequest + 容器展开 或 直接 LayoutDoc
    ↓
typst_gen → PDF / SVG
```

| 层 | 职责 |
|----|------|
| `ExamBundle` | 内容装配（题面、答案） |
| **`PublicationDocument`** | 结构、顺序、容器、样式集、**文档模板（page）** |
| `LayoutDoc` | Typst 可渲染块序列 |
| `LayoutSpec` | 纸张/边距/页眉等（嵌在 Document.page） |

### 4.2 顶层结构（契约）

见前端：`frontend/src/types/publication.ts`（与本文同步；下文「计划字段」可先于 TS 落地）。

要点：

- `kind`: `exam` | `handout` | `topic`（可扩展，不加自由文档；P3 前仅元数据，见 §3.1）  
- `body`: 有序 `PubBlock[]`（线性，容器内嵌 children）  
- `style_sets[]`: 可复用对象皮肤  
- `page`: **文档模板**；对齐现有 `LayoutSpec`（纸张、`columns`、`margins`、`header_footer`、`parent_pages`、`fonts`、`color` 等）；后续可扩底色 / 水印 / 品牌页眉  
- `export`: mode、答案开关等（对齐 `ExportMode` / options）

### 4.3 块类型（V1）

| `type` | 说明 | P0 | P2 |
|--------|------|----|----|
| `section` | 大题标题 | ✅ | |
| `question` | 引用 `question_id` + 可选分值/覆盖 | ✅ | |
| `rich_text` | 说明/导语 | 预留 | ✅ |
| `multi_column_box` | 局部多栏容器 | 预留结构 | ✅ 交互 |
| `callout` | 教师提示（可后置；与后端题级 callout 的术语对齐见 §七） | 预留 | |

### 4.4 容器规则

- 插入盒子：选中多个 block id → 包进 `multi_column_box.children`  
- 移除盒子：children 展开回父级原位；**不删题目**  
- 盒子样式：内联 `box_style` 或 `style_set_id`  
- 全局 `page.columns` 与盒子内 `columns` **并存**（整卷 vs 局部）  
- P2 起盒子可声明 `column_widths`（如左题右笔记比例）；与全局栏旋钮分离  

**嵌套限制（硬规则）**：

- `multi_column_box` **不可嵌套**（盒内不允许再放盒）；  
- 全局为多栏（`page.columns > 1`）时，盒内栏数 **≤ 2**；  
- A3 对折 + 全局多栏 + 盒内栏的三重叠加**禁止**（Typst 嵌套 columns 有实测坑，见 §七）。

### 4.5 对象皮肤 `BoxStyle`（计划契约）

在现有颜色/圆角/标题字段上，文档约定增加：

- `variant`: `frame` | `side_tab` | `badge_top` | `ornate_corner` | …（有限枚举，双端登记）  
  **实现状态：仅文档约定，TS 未落地**（落地时写入 `publication.ts`）。  
- 侧签/徽章方位等参数随 variant 解释，**方位用枚举**（九宫格 `top_left | top_center | …`）；  
  现有 TS 的 `title_pos: { x_pct, y_pct }` 自由百分比与「禁止自由几何」纪律冲突，**落地 variant 时改为枚举方位，不新增自由坐标字段**。  
- **禁止**把任意 CSS 字符串存进可持久化样式。

每个 `variant` ↔ 一个 Typst 皮肤函数 + 一个 HTML 主题组件（档 B 启用后 HTML 侧不再登记，见 §六）。

### 4.6 编译口径与 API 契约

**降级口径（显式约定）**：

- **P0/P1**：预览与导出走 `sectionsFromDocument()` → `ExamRequest` 现有路径；**容器被拍平、`rich_text` / `callout` / `style_set_id` 被丢弃，属预期降级**，不作缺陷处理。  
- **P2 起**：导出与校对吃完整 `PublicationDocument` 编译结果，含容器与皮肤。

**P2 API 形态（启动时二选一落定）**：

| 方案 | 内容 | 影响 |
|------|------|------|
| A. 扩展 `ExamRequest` | 加 `containers` / `style_sets` 字段 | 改动小；契约越来越宽，长期难维护 |
| B. 新增 `POST /typeset/compile` | 直接吃 `PublicationDocument` | 契约干净；前端预览 / 导出 / 档 B bbox 共用一条管线，**推荐** |

落定后同步：ts-rs 生成类型、前端 `exportApi` / 预览调用、档 B 的 bbox metadata 下发字段（§六）。

**后端 IR 变更面（`src/typeset/`）**：

- `LayoutBlock` 增加 `Container` 变体（皮肤 + columns + children）；  
- 影响面：`meta()` / `meta_mut()` / `question_no()` 访问器、`keep_with_next` 链尾收尾逻辑需适配嵌套；  
- docx 路径已冻结（`DOCX_ENABLED = false`）：`Container` 在 docx 出口可直接跳过或报错，不做 parity。

**编译步骤（P2）**：

1. 线性展开 `body`；遇盒子则生成带皮肤的容器（`#block` / `#columns` / `#grid`）  
2. `question` 块经现有 assembler 取题面；有 `style_set_id` 则外包对应皮肤  
3. `page` + `export` → 现有 `resolve_spec` / `ExamRequest` 路径（母版页眉页脚页码走现有 typst 母版）

### 4.7 生命周期与异常态

**往返一致性（试题篮 ↔ Studio）**：

- 现状风险：`Basket.openTypeset()` 每次重新 `documentFromSections()` 并覆盖 `studio_document`，Studio 内的排序 / 装盒 / 样式会**全部丢失**。
- 规则（P1 落地）：文档记录 `source_fingerprint`（试题篮内容 hash）。进入 Studio 时：
  - 指纹一致 → **恢复**已有文档（保留排版编辑）；
  - 指纹不一致 → 提示「恢复上次排版 / 按当前试题篮重建」，用户显式选择。

**异常态**：

| 场景 | 口径 |
|------|------|

## 六、档 B：Typst 视觉单源与热区（优化补充，未启用）

> **定位**：本文档主线（§一～§五）的**优化与补充**，非现行默认。  
> **状态**：未启用 · 显式切换前 §3.3 双端口径有效。  
> **关系**：交互（装盒 / 套样式 / 双层模板 / 性能硬约束）**继承**；视觉实现从「HTML↔Typst 双端皮肤」改为「**仅 Typst**」。

### 6.1 目标与动机

| 痛点（双端路径） | 档 B 目标 |
|------------------|-----------|
| 每个 `variant` 须 HTML + Typst 双侧登记，易漂移 | **消除双端皮肤维护**：皮肤 / 母版 / 公式视觉只在 Typst |
| 编辑画布是结构投影，校对才是印张 | **编辑区也可接近印张**：所见与 PDF 同引擎 |
| 长卷下 HTML + KaTeX 盒皮仍是性能压力源 | 编辑面以 **当前页 SVG + 热区** 为主，不再依赖全量 KaTeX 盒皮 |

产品交互不变：老师仍用「对象树 / 装盒子 / 套样式 / 调文档模板」；变的是中栏视觉源。

### 6.2 架构

```
PublicationDocument（唯一可写）
        │
        ▼ compile（与校对 / 导出同一管线）
typst_gen → 当前页 SVG + 块 bbox 元数据
        │
        ▼ 前端投影
IR 全量持有 + 当前页 SVG + 透明热区（点选 → selectedId）
```

| 层 | 职责 |
|----|------|
| **`PublicationDocument`** | 唯一可写真相源；结构 / 样式 / 文档模板；画布不存第二套坐标 |
| **Typst** | **唯一**皮肤 / 母版 / 公式视觉真相；校对与导出同源编译 |
| **前端** | IR 全量；中栏挂 **当前页 SVG**；其上叠 **透明热区** 承接点选 |
| **对象树 / 右栏** | 与主线一致：树选中 ↔ `selectedId`；文档模板 \| 对象属性 |

校对 Tab 与编辑面在档 B 下可共用同一 SVG 管线（仍只挂当前页）；不再维护「印刷级 HTML 皮肤组件库」作为可保存样式的视觉源。

### 6.3 与主线对照

| 维度 | 主线（现行） | 结构态（＝§3.4 口径） | **档 B（优化方案）** |
|------|--------------|------------------------|----------------------|
| 编辑中栏 | HTML 工作画布（虚拟化）+ 校对 Tab 单页 SVG | 结构态长卷为主；内容靠邻域展开；校对仍单页 SVG | **当前页 SVG + 透明热区**；可选邻页预取 |
| 皮肤登记 | HTML 组件 + Typst 函数，几乎同款 | 同主线（结构态可弱化盒皮） | **仅 Typst**；前端不维护印刷级 CSS 皮肤库 |
| 视觉一致性 | 双端 token / 肉眼接近；分页以 Typst 为准 | 结构态与印张差距更大，靠校对 Tab 对齐 | 编辑所见与 PDF **同引擎**；分页/盒皮/公式视觉同源 |
| 点选 | HTML 块 DOM | 结构轮廓 / 树 | **热区** → `selectedId`；无 bbox 降级侧栏树 |
| 公式 | 画布 KaTeX；导出 mitex→Typst | 结构态少挂 KaTeX | **Typst 渲染进 SVG**；编辑面不依赖全量 KaTeX 盒皮 |
| 文本选择 | 画布 DOM 可划词复制 | 结构态不可 | **SVG 字形描边不可选**（已知损失，见 §6.8）；右栏属性面板提供题面文本 |
| 生效方式 | 主线默认 | 可选折中 | **优化方案**；显式切换后才取代 §3.3 |

### 6.4 交互（继承主线，换命中面）

仍沿用 §3.1 / §3.2；档 B 差异仅在命中：

| 动作 | 行为 |
|------|------|
| 点正文块热区 | → `selectedId`；右栏出对象属性 |
| 点母版区热区（页眉/页脚/水印等） | → 打开「文档模板」面板；不设正文 `selectedId` |
| 点空白 / 无映射区 | 保持或清空选中（产品可选）；不写坐标到 IR |
| Ctrl/⌘ + 点热区、框选 | **多选**（装盒前提）；多选状态不写坐标到 IR |
| 拖拽热区排序手柄 | 只改 `body` 顺序；落点由 IR 结构决定，**不写几何** |
| 重叠热区（徽章压住题面等） | 命中优先级：**深层块优先**（children > 盒子 > 母版区）；同层取先命中 |
| 编辑后选中块跨页迁移 | 视图自动跳至该块所在页并维持高亮 |

装盒 / 拆盒 / 套样式的数据变更仍只写 `PublicationDocument`；视觉靠 debounce 全文热重编、只换当前页 SVG（沿用现有 `/typeset/preview` 节奏，重编口径见 §6.6）。

### 6.5 命中映射（档 B 关键）

| 项 | 口径 |
|----|------|
| 映射 | 块 `id` → **页内 bbox**（单一路线：`typst_gen` 为每个 `LayoutBlock` 挂 label，编译期经 query / 帧树导出 `id → bbox` JSON，随编译响应扩展字段下发；实现基础：`compiler.rs` 已走帧树） |
| 母版区热区 | 页眉/页脚/水印不在 body 块流，同样靠编译期 label 导出 bbox；命中打开「文档模板」面板 |
| 热区 | 透明 overlay，几何与 bbox 对齐；点击命中 id |
| 跨页块 | 每页各自 bbox；选中态可跨页高亮同一 id（实现可选） |
| **无 bbox** | **降级**：侧栏对象树选中；不阻塞结构编辑 |
| 禁止 | 把热区坐标回写为 IR 几何真相；自由拖拽改印刷坐标（非主线） |

bbox 契约可后置于 `typst_gen` / 编译 API（§4.6 方案 B 落定后随其下发）；文档侧先冻结「有则热区、无则树」的产品行为。

### 6.6 性能（硬约束，对齐主线并收紧视觉侧）

教师讲义可达 **150～200 页**。档 B 与 §3.4 DOM 纪律一致，并明确不再依赖全量 KaTeX 盒皮。

| 规则 | 要求 |
|------|------|
| 禁止 | **整卷 SVG** 一次挂进 DOM |
| 中栏 | **只挂当前页** SVG（邻页预取 ±1，LRU 上限 ≤5 页，防内存回升） |
| IR | **全量**持有于内存；与 DOM / SVG 规模脱钩 |
| 对象树 | 可虚拟滚动 |
| 公式 / 盒皮 | 视觉在 Typst SVG 内；**不再**以全量 KaTeX + HTML 盒皮支撑编辑面 |
| 重编 | **始终全文重编**（Typst 分页是全局布局结果，不存在按页重编）；靠 comemo 增量缓存的热编译 + debounce + 过期请求丢弃控制延迟 |
| 编译延迟 | 热重编预算 **P95 < 2s**（百页讲义实测填数；基建见 `compiler.rs` cold/warm 对比测试） |
| 反馈模型 | **乐观更新**：对象树 / 右栏即时反映数据变更，SVG 与热区延迟到达；超预算时编辑期降级结构态轮廓，校对再上 SVG |

性能验收：一屏内挂载页数与总页数近似无关；百页+ 文档可滚动、可点选，不因整卷 SVG/KaTeX 卡死。

### 6.7 分期与切换

主线 P0～P2 仍按双端皮肤推进。档 B 为 **P2 皮肤进 Typst 之后** 的后续增强：

| 编号 | 相对主线 | 目标 | 依赖 |
|------|----------|------|------|
| **P2.5**（可选） | P2 之后 | bbox spike：label + 帧树/query 导出验证（`compiler.rs` 帧树基建）→ 编译 API 附带块 id→bbox；Studio 校对/试验层叠热区验证点选 | 现有 `/typeset/preview` 单页 SVG |
| **P5 档 B**（可选） | P5+ 增强槽 | 编辑中栏切换为「SVG + 热区」主路径；**新皮肤只登记 Typst 单端；存量 HTML 皮肤保留为结构态底图**（长卷导航 / 邻域轮廓），不再投入印刷级对齐 | P2 Typst 皮肤完备；bbox 稳定；热区降级策略可用 |

切换条件（产品）：显式决定「视觉单源 = Typst」后，再将 Studio 编辑 Tab 从 HTML 画布迁到档 B；此前主线双端路径并行有效。

**切换后 HTML 画布不废弃**：保留为结构态长卷导航与邻域轮廓层（延续 §3.4 口径），档 B 在其上补视觉保真层。

显式切换时，本文以下条款同步修订（以档 B 为准）：

| 位置 | 原口径 | 切换后 |
|------|--------|--------|
| §2.2 P1 行 | HTML 工作画布（点选 + 块级虚拟化） | 结构态 HTML 画布（导航）+ 当前页 SVG 热区（视觉） |
| §2.3 主线第 6 条 | 样式集 = HTML 皮肤 + Typst 同名函数 | 样式集 = Typst 单端；HTML 侧仅结构态轮廓 |
| §3.3 整节 | 双端登记、几乎同款 | 视觉单源 = Typst（本节由档 B 替代） |
| §3.4 表末行 | 主编辑技术 = HTML + `LatexRender` | 主编辑技术 = 结构态 HTML + 当前页 SVG 热区 |
| §4.5 末行 | 每 variant ↔ Typst 函数 + HTML 组件 | 每 variant ↔ Typst 函数（HTML 侧不登记印刷级组件） |
| §9.2 P1 验收 | HTML 画布块级虚拟化 | 结构态画布虚拟化 + 热区命中验收（见 §6.8） |

### 6.8 明确不做与已知损失

**明确不做**：

- **Typst → HTML** 作为主编辑画布（反向生成可编辑 DOM）  
- 前端 **印刷级 CSS 皮肤库** 作为可保存样式的视觉源（档 B 下）  
- **整卷 SVG** 进 DOM  
- 自由画框 / 钢笔 / 复杂绕排 / 图层（与主线一致）  
- 用热区坐标污染 `PublicationDocument` 几何  
- 覆盖或改写主线条款以「静默生效」档 B  

**已知损失（切换时接受）**：

- 编辑面 SVG **文本不可划词选中 / 复制**（typst-svg 把字形描成 `<path>`）；对策：右栏对象属性提供题面文本，必要时保留只读文本层。  
- 编辑反馈存在**编译延迟**（相对 HTML 画布的零延迟）；对策：乐观更新 + 结构态降级（见 §6.6）。

## 七、术语对齐与风险

### 7.1 术语对齐

| 名词 | 前端（`publication.ts`） | 后端（`src/typeset/ir.rs`） | 口径 |
|------|---------------------------|------------------------------|------|

### 7.2 已知风险与现状

- **Typst 嵌套 columns**：全局栏 + 盒内栏嵌套有实测坑 → 以 §4.4 嵌套限制规避；新组合先 spike 再进契约。

- **编译耗时**：百页讲义冷编译量级未实测；P2.5 用 `compiler.rs` cold/warm 基建填数，再校 §3.4 / §6.6 的 2s 预算。  
- **SVG 体积**：百页卷整卷 SVG 约 4MB 量级 → 档 B 预取 LRU 上限（§6.6）不可放宽。
