## 四、关键实现细节

### 4.1 空答案检测逻辑（扩充版 — 覆盖纯空格）

```rust
/// 检测 correct_answer 是否为空
///
/// 空值定义：
/// - None / Value::Null
/// - {"kind":"choice","value":{"options":[]}} 等 options/blanks/subs 为空数组
/// - {"kind":"text","value":"   "} 纯空格字符串（trim 后为空）
pub fn is_answer_empty(answer: &Option<serde_json::Value>) -> bool {
    match answer {
        None => true,
        Some(serde_json::Value::Null) => true,
        Some(v) => {
            if let Some(value) = v.get("value") {
                // 数组类答案：options/blanks/subs 为空数组
                if let Some(arr) = value.get("options").and_then(|o| o.as_array()) {
                    return arr.is_empty();
                }
                if let Some(arr) = value.get("blanks").and_then(|b| b.as_array()) {
                    return arr.is_empty();
                }
                if let Some(arr) = value.get("subs").and_then(|s| s.as_array()) {
                    return arr.is_empty();
                }
                // 字符串类答案：纯空格判定（覆盖 text/math 题型）
                if let Some(s) = value.as_str() {
                    return s.trim().is_empty();
                }
            }
            false
        }
    }
}
```

### 4.2 系统标签刷新逻辑（尊重 no_analysis_needed）

```rust
/// 根据答案与解析状态刷新 metadata.system_flags
pub fn refresh_system_flags(
    metadata: &mut serde_json::Value,
    answer: &Option<serde_json::Value>,
    analysis: &Option<String>,
) {
    let flags = metadata
        .as_object_mut()
        .expect("metadata 应为 JSON 对象")
        .entry("system_flags")
        .or_insert_with(|| serde_json::json!({}));

    let flags_obj = flags.as_object_mut().unwrap();
    let no_analysis_needed = flags_obj
        .get("no_analysis_needed")
        .and_then(|v| v.as_bool())
        .unwrap_or(false);

    flags_obj.insert(
        "pending_answer".to_string(),
        serde_json::Value::Bool(is_answer_empty(answer)),
    );
    // no_analysis_needed=true 时强制 missing_analysis=false
    let analysis_empty = analysis.as_ref().map_or(true, |s| s.trim().is_empty());
    flags_obj.insert(
        "missing_analysis".to_string(),
        serde_json::Value::Bool(analysis_empty && !no_analysis_needed),
    );
}
```

### 4.3 提交审核校验门（答案 + 选项 + 解析）

```rust
// submit_for_review 中，状态校验通过后追加：

// 1. 答案校验
if is_answer_empty(&existing.correct_answer) {
    return Err((StatusCode::UNPROCESSABLE_ENTITY, Json(json!({
        "error": "题目尚未补全答案，无法提交审核",
        "code": "ERR_ANSWER_INCOMPLETE",
        "missing": ["correct_answer"]
    }))));
}

// 2. 选项校验（选择题必须校验 options 非空）
if matches!(existing.question_type.as_str(), "choice" | "multiple") {
    let options_empty = existing.options.as_ref().map_or(true, |o| {
        o.get("options").and_then(|arr| arr.as_array()).map_or(true, |a| a.is_empty())
    });
    if options_empty {
        return Err((StatusCode::UNPROCESSABLE_ENTITY, Json(json!({
            "error": "选择题尚未填写选项内容",
            "code": "ERR_OPTIONS_INCOMPLETE",
            "missing": ["options"]
        }))));
    }
}

// 3. 解析校验（no_analysis_needed=true 时豁免）
let no_analysis_needed = existing.metadata
    .get("system_flags")
    .and_then(|f| f.get("no_analysis_needed"))
    .and_then(|v| v.as_bool())
    .unwrap_or(false);
let analysis_empty = existing.analysis.as_ref().map_or(true, |s| s.trim().is_empty());
if analysis_empty && !no_analysis_needed {
    return Err((StatusCode::UNPROCESSABLE_ENTITY, Json(json!({
        "error": "题目尚未补全解析，无法提交审核",
        "code": "ERR_ANALYSIS_INCOMPLETE",
        "missing": ["analysis"]
    }))));
}
```

### 4.4 「待补全」SQL 筛选（`@>` 包含操作符命中 GIN 索引）

```sql
-- ⚠️ 必须使用 @> 包含操作符，不能用 ->>'pending_answer' = 'true'
-- ->> 返回 text 类型，会绕过 GIN 索引退化为 Seq Scan
-- @> 返回 jsonb 类型，完美命中 GIN 索引 → Bitmap Index Scan

-- 筛选待补全答案的草稿题目
SELECT * FROM questions
WHERE status = 'draft'
  AND metadata->'system_flags' @> '{"pending_answer": true}'::jsonb
ORDER BY created_at DESC
LIMIT $1 OFFSET $2;

-- GIN 索引（T1-11，Blocker）
CREATE INDEX CONCURRENTLY IF NOT EXISTS idx_questions_system_flags
  ON questions USING GIN (metadata->'system_flags');

-- 验证：EXPLAIN ANALYZE 确认走 Bitmap Index Scan（非 Seq Scan）
-- EXPLAIN ANALYZE SELECT * FROM questions
--   WHERE metadata->'system_flags' @> '{"pending_answer": true}'::jsonb;
```

```rust
// ai_parse_worker.rs — save_parsed_question 中

let correct_answer_json = match &parsed.correct_answer {

    "[AI提取题干失败，请老师人工补充]".to_string()
} else {
    parsed.stem.clone()
};

// 保存为 Draft + system_flags 由 create_question 的 refresh_system_flags 自动填充
```

## 七、风险与回滚

| 风险 | 回滚方案 |
|---|---|
| `correct_answer` 改为 Option 导致下游类型不匹配 | 编译期即可发现，`cargo check` 保证 |
| `system_flags` 查询退化为 Seq Scan | **必须用 `@>` 包含操作符**（非 `->>`），命中 GIN 索引 |
| 批量提交审核超时 | 单题独立事务，已提交的不回滚 |
| 开放题被误判为"缺解析" | `no_analysis_needed` Override 豁免 |
| GIN 索引创建耗时（大表） | `CONCURRENTLY` 不锁表，可在低峰期执行 |
| AI 灾难级失败导致 stem 为空违反 NOT NULL | **stem 兜底占位符** `[AI提取题干失败，请老师人工补充]` |
| 批量失败后跳转编辑丢失 Modal 上下文 | **新标签页/抽屉打开**，不破坏列表页状态 |
