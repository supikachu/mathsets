## 3. Gap 明细

### 🔴 GAP-1：AI 标注的 source 与 ai_confidence 在用户编辑时被全量覆盖丢失

**严重度**：高（影响 AI 录题审计追溯）

**位置**：[src/handlers/questions.rs:62-109](file:///c:/Users/pikachu/Desktop/mathset/src/handlers/questions.rs#L62-L109)

**问题详述**：

`update_knowledge_nodes` 函数采用「先 DELETE 全部旧关联，再以 `source='manual'` 重新插入」的实现策略。而 AI 批量录题链路（`upsert_ai_knowledge_nodes`）写入的 `source='ai'` 与 `ai_confidence` 分数，**在用户首次编辑保存后被全量覆盖清零**，违反 B3 审计追溯设计意图。

**触发路径**：

```
1. AI 批量录题 → question_knowledge_nodes.source='ai', ai_confidence=0.87
2. 用户在前端编辑题目 → 提交 knowledge_node_ids（含原节点）
3. handler 调用 update_knowledge_nodes → DELETE + INSERT source='manual'
4. 审计数据丢失（source 与 ai_confidence 被抹平为 manual / NULL）
```

**关键代码片段**：

```rust
// src/handlers/questions.rs:62-109
pub(crate) async fn update_knowledge_nodes(...) {
    sqlx::query("DELETE FROM question_knowledge_nodes WHERE question_id = $1")
        .bind(question_id)
        .execute(&mut **tx).await?;

    for node_id in node_ids {
        let is_primary = primary_node_id == Some(*node_id);
        sqlx::query(r#"
            INSERT INTO question_knowledge_nodes
              (question_id, node_id, is_primary, source, created_at)
            VALUES ($1, $2, $3, 'manual', NOW())   -- ⚠️ 硬编码 'manual' 覆盖 AI 标注
            ON CONFLICT (question_id, node_id) DO NOTHING
        "#)
        // ...
    }
}
```

**修复建议**：

参考 `update_question_tags`（[src/handlers/questions.rs:199-258](file:///c:/Users/pikachu/Desktop/mathset/src/handlers/questions.rs#L199-L258)）的差分更新模式：
1. 查询当前已有关联（含 source/ai_confidence）
2. 计算 `removed` / `added` / `retained` 三个集合
3. 仅对 `removed` 执行 DELETE
4. 仅对 `added` 执行 INSERT（source='manual'）
5. `retained` 集合保留原 source 与 ai_confidence 不动

**严重度**：中（性能，题量大时显现）

**位置**：

- 索引定义：[migrations/20260718000001_question_model_refactor.sql:69](file:///c:/Users/pikachu/Desktop/mathset/migrations/20260718000001_question_model_refactor.sql#L69)

**问题详述**：

迁移建了 `idx_questions_stem_text_gin`（GIN to_tsvector 索引），但 `apply_question_filters` 仍用 `q.stem ILIKE '%keyword%'` 全表扫描，索引形同虚设：

```rust
// src/handlers/questions.rs:701-704
if let Some(ref keyword) = query.keyword {
    builder.push(" AND q.stem ILIKE ");
    builder.push_bind(format!("%{}%", keyword));

```

同时 AI 录题 worker 写入 `stem_text` 时硬编码为 NULL：

```rust
// src/workers/ai_parse_worker.rs:281

```

**修复建议**：

```rust

builder.push(" AND (q.stem ILIKE ");
builder.push_bind(format!("%{}%", keyword));
builder.push(" OR to_tsvector('simple', COALESCE(q.stem_text, q.stem)) @@ plainto_tsquery('simple', ");
builder.push_bind(keyword);
builder.push("))");

// 2. ai_parse_worker.rs:281 填充 stem_text（去 LaTeX 后的纯文本）
.bind(Some(&parsed.stem_plain_text))  // 替代 NULL
```

### 🟢 GAP-6：`question_knowledge_nodes` 缺组合索引支撑多维检索

**严重度**：低（性能，数据量大时显现）

**位置**：[migrations/20260721000001_tag_system_recover.sql:279-281](file:///c:/Users/pikachu/Desktop/mathset/migrations/20260721000001_tag_system_recover.sql#L279-L281)

**问题详述**：

现有索引为 `(question_id)`、`(node_id)`、`(source)` 单列索引。`apply_question_filters` 中的多维查询模式是：

```sql
WHERE qkn.question_id = q.id AND qkn.node_id = ANY(...)
```

最优索引应是 `(node_id, question_id)` 组合索引。当前 `node_id` 单列索引需回表后才能过滤 `question_id`。

**修复建议**：

```sql
CREATE INDEX IF NOT EXISTS idx_qkn_node_question
  ON question_knowledge_nodes(node_id, question_id);
```

## 5. 数据库调整建议

新建迁移 `20260802000001_align_knowledge_node_audit.sql`：

```sql
BEGIN;

-- ============================================================
-- GAP-3: knowledge_nodes.question_count 维护触发器
-- 应用层差分更新已落地时，触发器作为兜底保险
-- ============================================================
CREATE OR REPLACE FUNCTION sync_question_count() RETURNS TRIGGER AS $$
BEGIN
  IF (TG_OP = 'INSERT' OR TG_OP = 'DELETE') THEN
    UPDATE knowledge_nodes
    SET question_count = (
      SELECT COUNT(*) FROM question_knowledge_nodes
      WHERE node_id = COALESCE(NEW.node_id, OLD.node_id)
    )
    WHERE id = COALESCE(NEW.node_id, OLD.node_id);
  END IF;
  RETURN NULL;
END;
$$ LANGUAGE plpgsql;

CREATE TRIGGER trg_qkn_sync_count
  AFTER INSERT OR DELETE ON question_knowledge_nodes
  FOR EACH ROW EXECUTE FUNCTION sync_question_count();

-- ============================================================
-- GAP-5: 清理 deprecated 列
-- ============================================================
ALTER TABLE questions
  DROP COLUMN IF EXISTS academic_year,
  DROP COLUMN IF EXISTS grade_semester,
  DROP COLUMN IF EXISTS exam_region,
  DROP COLUMN IF EXISTS grade;

-- ============================================================
-- GAP-6: 多维检索组合索引
-- ============================================================
CREATE INDEX IF NOT EXISTS idx_qkn_node_question
  ON question_knowledge_nodes(node_id, question_id);

COMMIT;
```
