# 协同题库系统 — 业务需求文档

> 版本：v0.1 · 初稿
> 目标读者：开发团队、产品、教研组长
> 适用学段：初中数学（7-9 年级）、高中数学（10-12 年级）

---

## 1. 项目背景与目标

### 1.1 背景

初中及高中数学教学过程中，教师日常需要大量题目用于课堂练习、课后作业、阶段测验、期中期末考试。目前题目分散在各个教师的个人文档中，缺乏统一管理、缺乏质量审核、缺乏跨年级协同。

### 1.2 目标

构建一个**多教师协同的题库系统**，实现：

- 题目统一存储、分类、检索
- 多人协作编辑 + 审核发布流程
- 结构化知识点分类体系
- 支撑组卷出题（手动/智能）
- 版本可追溯，内容可审核

### 1.3 范围

| 纳入范围 | 不纳入范围（v1） |
|----------|-----------------|
| 初中数学（7-9 年级） | 在线考试/答题系统 |
| 高中数学（10-12 年级） | 自动批改 |
| 选择题 / 填空题 / 解答题 / 判断题 | 学生端 App |
| 题目审核协作流程 | 学情分析 |
| 知识点树维护 | 智能推荐算法 |
| 组卷功能 | OCR 识别纸质题 |

## 2. 用户角色

### 2.1 角色定义

| 角色 | 描述 | 系统权限 |
|------|------|----------|
| **系统管理员** | 运维和配置管理 | 用户管理、角色分配、数据备份恢复、系统设置 |
| **教研组长** | 学科内容负责人 | 知识点树维护、审核发布、驳回、成员管理、统计分析 |
| **教师** | 日常出题用题 | 创建/编辑草稿、提交审核、引用已发布题目、组卷 |
| **浏览者**（可选） | 新教师或外部访问 | 只读查看已发布内容 |

### 2.2 教研组

- 教师归属于一个或多个**教研组**（如：初一数组、初三几何组、高考冲刺组）
- 每个教研组至少有一名**教研组长**
- 题目审核只能由同组组长执行（**同组审核，创建者回避**）
- 教师可以将题目在不同组之间共享

## 3. 题目实体

### 3.1 字段定义

```
题目 (Question)
├── id              : 全局唯一标识
├── stem            : 题干（支持 LaTeX / 富文本）
├── question_type   : enum { 选择题, 填空题, 解答题, 判断题, 综合题 }
├── difficulty      : enum { 基础, 中档, 困难 } 或 1-5 星
├── default_score   : 默认分值（正整数）
├── status          : enum { 草稿, 待审核, 驳回, 已发布, 已停用 }
│
├── answers         : 答案信息（按题型不同结构，见 3.2）
├── solution        : 详细解答过程（富文本 / LaTeX）
│
├── knowledge_tags  : [知识点标签 ID] — 多对多关联
├── grade           : 适用年级（初一/初二/初三/高一/高二/高三）
├── semester        : 上学期/下学期/全学年
│
├── source          : enum { 原创, 改编, 引用 } + 来源说明
│
├── creator_id      : 创建者
├── created_at      : 创建时间
├── updated_by      : 最后编辑者
├── updated_at      : 最后编辑时间
├── version         : 版本号（单调递增）
│
├── review_comment  : 最近一次审核意见
└── reviewed_by     : 最近一次审核人（组长）
```

### 3.2 题型特定结构

#### 选择题

```
- options: [
    { label: "A", content: "..." },
    { label: "B", content: "..." },
    { label: "C", content: "..." },
    { label: "D", content: "..." }
  ]
- correct_answers: ["A"]   // 单选数组长度=1，多选>1
- analysis: "逐个选项解析"
```

#### 填空题

```
- blanks: [
    { position: 1, answer: "…", tolerance: null }  // tolerance 用于数值容差
  ]
- allow_multiple_blanks: true
```

#### 解答题

```
- reference_answer: "完整解答"
- grading_criteria: [
    { step: "列式", points: 2 },
    { step: "计算", points: 3 },
    { step: "结论", points: 1 }
  ]
```

#### 判断题

```
- correct: true / false
- analysis: "错误原因解析"
```

### 3.3 题目生命周期

```text
     ┌──────────┐
     │   草稿    │ ◄──── 教师创建
     └────┬─────┘
          │ 教师提交
          ▼
     ┌──────────┐
     │  待审核   │
     └────┬─────┘
         ╱ ╲
        ╱   ╲
       ▼     ▼
  ┌────────┐ ┌──────────┐
  │ 已发布  │ │  驳回     │
  └────┬───┘ └────┬─────┘
       │          │ 教师重新编辑
       │          ▼
       │     ┌──────────┐
       │     │   草稿    │ （生成新版本）
       │     └──────────┘
       │
       │ 组长下架
       ▼
  ┌──────────┐
  │ 已停用   │
  └──────────┘
```

**状态规则：**

| 状态 | 谁可编辑 | 谁可见 | 可否用于组卷 |
|------|----------|--------|-------------|
| 草稿 | 创建者本人 | 仅创建者 | ❌ |
| 待审核 | 无人（只读锁定） | 全组教师（只读） | ❌ |
| 驳回 | 创建者本人 | 创建者 + 审核组长 | ❌ |
| 已发布 | 无人（只读） | 所有老师 | ✅ |
| 已停用 | 无人（只读） | 所有老师（标记停用） | ❌（已有引用不受影响） |

### 3.4 版本控制

- 每次编辑保存都作为**一个版本**记录
- 版本包含完整的题目快照 + 变更说明
- 已发布的题目如果需要修改：创建者创建一个**新版本**（=> 草稿状态），走重新审核
- 旧版本永远可追溯

### 4.2 知识点管理规则

- 知识点为**树形结构**，最多 4 层深度
- 一道题可关联**1~5 个**知识点标签
- 知识点树的维护权限归**教研组长**
- 支持：新增、重命名、移动（改父节点）、合并、删除（需检查无关联题目）
- 每个知识点可标记**适用年级/学期**

## 5. 协作与审核流程

### 5.1 单人编辑锁

- 当教师打开题目编辑时，系统加**悲观锁**
- 加锁后其他教师只能**只读查看**，不可编辑
- 编辑超过 30 分钟无操作 → 锁自动释放（防占位）
- 教师主动关闭编辑器 → 释放锁

### 5.2 审核流程

```text
教师提交审核
    │
    ▼
系统规则校验:
├── 题干不为空
├── 答案不为空
├── 至少关联一个知识点
├── 难度已设置
└── LaTeX 语法检查（可选）
    │
    ▼
通知同组组长 → 组长进入审核
    │
    ├── 通过 → 状态变为 [已发布]
    │           可选择附带审核意见
    │
    └── 驳回 → 状态变为 [驳回]
                必须填写驳回原因
                通知原创建者
```

### 5.3 通知机制

| 事件 | 通知谁 | 通知方式（v1） |
|------|--------|----------------|
| 题目提交审核 | 本组所有组长 | 站内消息 |
| 审核通过 | 创建者 | 站内消息 |
| 审核驳回 | 创建者 | 站内消息 + 驳回原因 |
| 题目被引用到试卷 | 创建者 | 可选通知 |
| 题目被停用 | 创建者 | 站内消息 |

## 6. 组卷功能

### 6.1 手动组卷

1. 教师新建试卷，设定标题、考试类型（周测/月考/期中/期末/作业）
2. 设定试卷结构：题型分布、题量、总分
3. 从题库按条件检索题目，逐题添加到试卷
4. 调整题目顺序，每道题可独立设置**分值**（覆盖默认值）
5. 保存为草稿 / 发布 / 导出

### 6.2 自动组卷（简易版 v1）

1. 教师输入参数：题型 × 道数、知识点范围、难度分布、总分
2. 系统按条件从**已发布**题库中抽样
3. 生成试卷草稿，教师可手动调整

### 6.3 试卷实体

```text
Paper (试卷)
├── id
├── title
├── exam_type    : enum { 周测, 月考, 期中, 期末, 作业, 竞赛 }
├── grade        : 适用年级
├── total_score  : 总分
├── duration     : 建议用时（分钟）
├── questions    : [
│   { question_id, order, custom_score, optional: bool }
│  ]
├── status       : enum { 草稿, 已发布, 已使用, 归档 }
├── creator_id
├── created_at
└── updated_at
```

## 7. 搜索与检索

### 7.1 题目搜索条件

- 关键词（模糊匹配题干）
- 题型（单选题/多选题/填空题/解答题/判断题）
- 难度（基础/中档/困难）
- 知识点（树形选择，含子树搜索）
- 年级 + 学期
- 状态（已发布 / 草稿 / 待审核）
- 创建者
- 创建时间范围
- 来源（原创/改编/引用）
- 是否有答案

### 7.2 搜索结果

- 以列表形式展示：题干摘要 + 题型 + 难度 + 状态 + 创建者 + 创建时间
- 可点击进入详情
- 支持多选（用于批量审核、批量添加至试卷）

## 8. 非功能需求

| 需求 | 说明 |
|------|------|
| LaTeX 渲染 | 题干、解答中的数学公式需支持 LaTeX 语法（配合前端渲染引擎） |
| 并发控制 | 悲观锁防止多人同时编辑同一题目 |
| 数据持久化 | 所有变更必须持久化到数据库，支持每日备份 |
| 审计日志 | 所有审核操作、状态变更、版本创建均记录日志 |
| 响应性能 | 搜索 < 2s，单题详情 < 500ms，试卷加载 < 3s |
| 访问控制 | 角色 + 教研组双重权限校验 |

## 9. 数据关系概览（ER 核心）

```text
Users ──1:N──> Questions       (创建者)
Users ──M:N──> Groups          (教研组成员)
Groups ──1:N──> GroupLeaders   (教研组长)

Questions ──M:N──> KnowledgePoints
Questions ──1:N──> QuestionVersions (编辑历史)
Questions ──1:N──> ReviewRecords    (审核记录)

Papers ──M:N──> Questions (通过 PaperQuestion 关联)
Papers ──> Users (创建者)

SystemLogs ──> 所有操作审计
```
