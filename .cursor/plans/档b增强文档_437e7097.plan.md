## 新文档写什么（相对终稿的差分，写全可读）

文首声明：

- 本文 = 在终稿产品需求之上的 **档 B 增强架构**；
- 与终稿关系：交互（装盒/套样式/双层模板/性能硬约束）继承；**视觉实现从「双端皮肤」改为「仅 Typst」**；
- 终稿中「HTML↔Typst 双端登记几乎同款」在本文中**被替代**，不以覆盖终稿方式生效。

正文结构（短表 + 硬边界，对齐终稿文风）：

1. **目标与动机**：消除双端皮肤维护；编辑区也可接近印张。
2. **架构**：`PublicationDocument` 唯一可写；Typst 唯一皮肤/母版/公式视觉；前端 IR + **当前页 SVG + 透明热区**；校对/导出同一编译管线。
3. **与终稿 / 档 A 对照表**：终稿双端皮肤 vs 档 A 结构态+校对 Tab vs 档 B SVG+热区（表内写清，档 B 为本文采纳）。
4. **交互**：仍为选中/套样式/装盒/文档模板；点选落在热区 → `selectedId`；母版区点进版面面板。
5. **命中映射（档 B 关键）**：块 id → 页内 bbox（编译 metadata / 帧查询）；无 bbox 时降级为侧栏树选中。
6. **性能**：整卷禁止；只挂当前页（邻页可选）；IR 全量；与终稿 DOM 纪律一致并写明「不再依赖全量 KaTeX 盒皮」。
7. **分期建议**（相对终稿编号，不改终稿表格）：在 P2 皮肤进 Typst 之后，档 B 热区为后续增强；可写 P2.5/P5 依赖现有 `/typeset/preview` SVG。
8. **明确不做**：Typst→HTML 主画布；前端印刷级 CSS 皮肤库；整卷 SVG 进 DOM。
9. **验收草案**：单页 SVG+热区可选中；改 `style_set_id` 后重编所见与 PDF 同引擎；百页不整卷挂载。
